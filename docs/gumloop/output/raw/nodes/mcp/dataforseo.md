# DataForSEO

> Run keyword research, competitor analysis, backlink audits, and AI mention tracking with AI-powered SEO automation.

DataForSEO is a pay-as-you-go SEO data provider. The DataForSEO MCP server lets you research keywords, analyze competitors, audit backlinks, pull live Google results, and track how AI assistants mention your brand, all using natural language.

## Prerequisites

None. DataForSEO works out of the box on Gumloop's shared account, billed in Gumloop credits.

If you have your own DataForSEO account, you can connect it instead. Your calls then run on your own API balance and cost **no Gumloop credits**. Add your API login and password on the [Credentials page](https://www.gumloop.com/personal/connectors).

<Info>
  The API password is generated by DataForSEO in your [API access dashboard](https://app.dataforseo.com/api-access). It is not your account password.
</Info>

## What Can It Do?

* **Research keywords** with search volume, difficulty, CPC, and search intent
* **Analyze competitors** by shared keywords, rankings, and traffic estimates
* **Audit backlinks**, referring domains, anchor text, and authority scores
* **Pull live Google results** for any keyword
* **Track AI mentions** of your brand, domain, or keywords across LLM answers, with the sources they cite

## Where to Use It

### In Agents (Recommended)

Add DataForSEO as a tool to any agent. The agent can then perform SEO research conversationally, choosing the right actions based on context.

**To add an MCP tool to your agent:**

1. Open your agent's configuration
2. Click **Add tools** → **Connect an app with MCP**
3. Search for the integration and select it
4. Connect your account, or skip to use Gumloop's

<Tip>
  You can control which tools your agent has access to. After adding an integration, click on it to enable or disable specific tools based on what your agent needs.
</Tip>

### In Workflows (Via Agent Node)

For automated pipelines, use an [Agent Node](/core-concepts/agent_node) with DataForSEO tools. This gives you the flexibility of an agent within a deterministic workflow.

### As a Custom MCP Node

You can also create a standalone MCP node for a specific action. This generates a reusable node that performs one task, useful when you need the same operation repeatedly in workflows.

<div className="rounded-2xl overflow-hidden border border-pink-200 dark:border-pink-800">

**To create a custom MCP node:**

1. Go to your node library and search for the integration
2. Click **Create a node with AI**
3. Describe the specific action you want (e.g., "Get ranked keywords for hubspot.com")
4. Test the node and save it for reuse

<Info>
  Custom MCP nodes are single-purpose by design. For tasks that require multiple steps or dynamic decision-making, use an agent instead.
</Info>

### AI Optimization (LLM Mentions)

These tools cover AI search visibility: which brands, domains, and pages LLM answers name and cite for a given keyword or domain.

| Tool                                     | Description                                                                                                        | Credits       |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------- |
| **Search LLM Mentions**                  | Get individual AI answers that mention a keyword or domain, with the sources they cite                             | 30 + 1/result |
| **Get LLM Mentions Historical**          | Get month-by-month mention counts and AI search volume for a keyword or domain                                     | 30 + 1/result |
| **Get LLM Mentions Timeseries Delta**    | Get the period-over-period change in mentions and AI search volume                                                 | 30 + 1/result |
| **Get LLM Mentions Timeseries New Lost** | Get the mentions a keyword or domain gained and lost over time, with AI search volume                              | 30 + 1/result |
| **Get Top Mentioned Domains**            | Get the domains AI answers cite most, broken down by location, language, and platform                              | 30 + 1/result |
| **Get Top Mentioned Domains Lite**       | Get the domains AI answers cite most, as a flat list of mention counts                                             | 30 + 1/result |
| **Get Top Mentioned Pages**              | Get the pages AI answers cite most, broken down by location, language, and platform                                | 30 + 1/result |
| **Get Top Mentioned Pages Lite**         | Get the pages AI answers cite most, as a flat list of mention counts                                               | 30 + 1/result |
| **Get Top Mentioned Brands**             | Get the brands AI answers name most alongside a keyword or domain, broken down by location, language, and platform | 30 + 1/result |
| **Get Top Mentioned Brands Lite**        | Get the brands AI answers name most alongside a keyword or domain, as a flat list of mention counts                | 30 + 1/result |

<Tip>
  The **Lite** variants return a flat list of mention counts instead of a full breakdown by location, language, and platform. Use them when you only need a ranking, and the full versions when you need to segment the data.
</Tip>

<Tip>
  Tools that return a list charge per result, so use the `max_limit` parameter to control both cost and response size. Asking for 10 keywords instead of 1000 is a large difference in credits.
</Tip>

## Example Prompts

Use these with your agent or in the Agent Node:

**Keyword research:**

```text theme={"dark"}
Get the search volume and difficulty for "digital nomad visa"
```

**Competitive analysis:**

```text theme={"dark"}
Who are the top organic competitors for monday.com?
```

**Keyword gap:**

```text theme={"dark"}
Which keywords do zapier.com and make.com both rank for?
```

**Backlink audit:**

```text theme={"dark"}
Show me the referring domains and anchor text for shopify.com
```

**Live results:**

```text theme={"dark"}
Get the top 10 Google results for "ai workflow automation" and summarize what each page covers
```

**AI mention tracking:**

```text theme={"dark"}
Which brands do AI assistants mention most for "workflow automation platform"?
```

**AI visibility over time:**

```text theme={"dark"}
Show me how mentions of gumloop.com in AI answers have changed month over month
```

**AI citation sources:**

```text theme={"dark"}
Which pages do AI answers cite most when asked about "ai agent builder"?
```

## Location and Language

Most tools accept `location_name` and `language_name`, defaulting to United States and English. Pass a country name such as "United Kingdom" or "Germany" to target a different market.

## Troubleshooting

| Issue                            | Solution                                                                                                                          |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Agent not finding the right data | Use exact domain names without https\://                                                                                          |
| "Invalid Field" error            | The location or language name was not recognized. Use a full country name such as "United States", not a code.                    |
| Empty results                    | The domain or keyword may have no data in that market. Try a broader location or a better known domain to confirm the tool works. |
| Credentials rejected             | Check you used the API password from your DataForSEO API access dashboard, not your account password.                             |
| Tool not available               | Verify the tool is [enabled in your agent's MCP configuration](/core-concepts/agents#tool-management-and-approvals)               |

<Tip>
  Agents chain tools together. Asking "Analyze competitor.com's SEO" will typically pull a rank overview, then ranked keywords, then competitors. If results seem off, review the agent's step-by-step reasoning.
</Tip>
