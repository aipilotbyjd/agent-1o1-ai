# Use Team Connectors

Team connectors only appear on agents that live in that team.

## Existing personal agent

1. On the [Home page](https://www.gumloop.com/hub), open the agent's **⋮** menu and choose **Move to Team**. Or open the agent and use **Move to Team** there.
2. Pick the destination team.

  <img src="https://mintcdn.com/agenthub/wBs_l4y1SVLfsNA7/images/help/6213090025_1.png?fit=max&auto=format&n=wBs_l4y1SVLfsNA7&q=85&s=abe97e0df97f6133249eb4b11eb924e9" alt="Move an agent to a team" width="1644" height="984" data-path="images/help/6213090025_1.png" />

3. Open the connector's three-dot menu.
4. Choose **Use Team Default** or **Use Specific Account**. See [Choose which account to use](/core-concepts/credentials#in-agents).

## New agent

Create the agent **inside the team**, add the connector, and pick the team account from the start.

## Good to know

* **Use Personal Default** still uses each runner's own account. That is usually what you want for Gmail.
* **Use Team Default / Specific Account** is for a shared inbox or CRM.
* Changing a team agent's connector affects everyone. Confirm before you save.
