# Usage / licensing note

This package is a tooling bundle for retrieving Gumloop's publicly available
documentation.

It intentionally does not include a bulk redistributed copy of the documentation.

Before putting downloaded documentation into a commercial product, check the
applicable Gumloop documentation terms, copyright/license terms, and any applicable
robots/usage restrictions. Use the material as reference/research where appropriate
and write your own implementation, documentation, UI, code, and product copy.

Official documentation:
https://docs.gumloop.com/

Official documentation index:
https://docs.gumloop.com/llms.txt
